# 第1节 · 完整自查清单

> 这不是考试，没有分数。
> 它是一份**知识点自查清单**——把入门运营该懂的基础知识全部列出来。
> 对照着看：会的打 ✅，模糊的标 ⚠️，不懂的圈出来去补。
> 全部 ✅ 之后，你就具备了独立运营一个产品的基础。

::: tip 怎么用
1. 通读一遍，每个问题问自己：「我真的清楚吗？」
2. 会的打 ✅，模糊的标 ⚠️，不懂的圈出来。
3. 圈出来的部分，就是你的**学习清单**——对照五级课程体系和「真实」运营实战经验栏目去补。
4. 定期回来看，目标是**全部 ✅**。
:::

## 模块一：平台认知与账号安全

> 底线模块。这些不懂，后面学再多都是在雷区里走路。

### 账号与权限

- ASIN / SKU / FNSKU / UPC / EAN / GTIN 分别是什么，互相什么区别？
- 卖家后台（Seller Central）的主要功能入口你都找得到吗？随便说一个功能，3 秒内能定位到吗？
- 主账号和子账号的区别是什么？你会不会创建子账号、分配权限？
- 美站、欧站、日站的后台是互相独立的——邮箱、收款、绩效都不通用，这点你清楚吗？
- 专业卖家（Professional）和个人卖家（Individual）有什么区别？月租多少、每单扣费差多少、功能差在哪？

### 账号关联与封号风险

- 你知道什么是账号关联吗？亚马逊怎么判定好几个号是同一个人的？
- 哪些因素会触发关联（同一 IP、同一台电脑、同一网卡、同一收款账户、同一公司、相似的产品线）？
- 如果一台电脑登过好几个亚马逊账号，会怎样？你知道怎么隔离吗（VPS、紫鸟浏览器这些）？
- 什么是二审？什么情况下会被要求提供水电煤账单，要准备什么材料？
- 欧洲站的 KYC 审核要哪些公司和个人资料？你能一次备齐吗？
- 视频审核、地址验证、增强审核，分别什么情况会触发？

### 收款与税务

- 亚马逊的钱怎么收到手里？Payoneer / WorldFirst / PingPong / 官方收款，你配过吗？
- 收款账户怎么和后台绑定？多久结算一次、多久到账？
- 美国站的 W-8BEN 表格你填过吗？为什么要填？
- 欧洲站的 VAT 是什么？哪些国家要注册、申报周期是怎样的？

### 账号健康

- 账户健康（Account Health）在哪看？健康评分现在多少？
- ODR、迟发率、取消率、有效追踪率（VTR）的安全阈值你记得住吗？
- 哪些指标超标会让 Listing 下架？哪些会让整个账号停用？
- 收到绩效通知（Performance Notification）或者 policy warning，你会怎么处理？

### 合规与红线

- 你知道哪些动作算操纵评论吗？刷单、测评返现、诱导好评——后果是什么？
- 商标侵权、专利侵权、版权侵权，三者有什么区别？被投诉了申诉流程是什么？
- 危险品（Hazmat）、带电池的产品、California Prop 65，这些合规类目有什么特殊要求？
- 欧洲站的 EPR（包装法、电池法、WEEE）你了解吗？哪些必须注册？
- 卖家行为准则（Code of Conduct）里禁止的行为有哪些，你心里有数吗？

## 模块二：选品与采购

> 入门阶段不要求你能选出爆款，但要求你**会判断一个产品值不值得做**。

### 市场判断

- 给你一个品类，你怎么判断它市场容量够不够大？
- 怎么评估一个品类竞争有多卷？垄断程度、新品能不能进去、评论门槛高不高？
- 这个品类主流卖多少钱，价格带怎么看？
- 怎么判断一个产品是不是季节性的？
- Best Seller 榜、新品榜、飙升榜，你会用吗？分别看什么？
- 怎么查一个产品有没有侵权风险（商标、专利）？

### 利润核算

- 一个产品从出厂到卖出去，中间都有哪些成本？你能一个不漏地列出来吗？
- 给你一组数据，你能手算出这个产品的毛利和利润率吗？
- 什么是盈亏平衡点？怎么倒推最低售价？
- 海运、空运、快递，三种物流方式对利润的影响有多大，你算过吗？

### 供应链

- 怎么找供应商？1688、展会、还有什么渠道？
- 跟工厂谈的时候，打样、起订量（MOQ）、交期、付款方式，这些怎么沟通？
- 怎么做品控（QC）？出货前验货的基本流程是什么？
- OEM 和 ODM 有什么区别？
- 怎么防止工厂把你的款式卖给别人？合同里要怎么写？

## 模块三：Listing 搭建基本功

> 一个合格的 Listing 是所有运营动作的基础。

### 关键词调研

- 什么是关键词？它对 Listing 和广告意味着什么？
- 你的关键词从哪里来？亚马逊搜索框联想、竞品标题、Brand Analytics、Helium 10 / 卖家精灵——这些挖词方法你都会吗？
- 核心词、长尾词、竞品词分别是什么？作用和区别在哪？
- 一个关键词的搜索量大不大、竞争激烈不激烈，你怎么判断？
- 一个产品一般要布局多少个词？核心词和长尾词怎么搭配？

### 上架操作

- Add Products 手动上架一个单品，你能独立完成吗？每个必填属性什么意思都清楚吗？
- 类目模板（Flat File）批量上传你会吗？
- 上传报错了怎么办？错误代码看得懂、能自己修吗？
- 什么是变体（父子 ASIN）？怎么创建和管理？
- 变体主题（颜色、尺码等）有规则限制，哪些类目允许什么变体，你了解吗？
- 类目节点（Browse Node）是什么？为什么节点选对了流量更精准？

### Listing 内容

- 标题怎么写才算合格？字符限制、关键词位置、可读性，你心里有标准吗？
- 五点描述应该写什么？怎么写买家才看得进去？
- Search Terms（后台搜索词）有什么规则？250 字节限制、不要重复标题里的词、不要写竞品品牌——这些你知道为什么吗？
- 主图、副图的规格要求（白底、尺寸、无水印、无文字）你记得住吗？
- 主图视频（Main Image Video）怎么上传？需要什么资质？
- 产品描述（Description）和 A+ 页面有什么区别？

### 品牌注册与 A+

- 品牌注册需要什么条件、什么材料？能解锁哪些功能？
- 品牌注册整个流程多久？你会操作吗？
- A+ 编辑器你会用吗？有哪些模块类型？
- A+ 页面对转化到底有多大作用？

### Listing 诊断

- 什么是 Suppressed Listing（被抑制）？怎么查看抑制原因？
- 常见的抑制原因有哪些（缺主图、标题太长、属性没填）？
- 报错后你会修吗？
- 怎么判断一条 Listing 的内容质量好不好？

### 竞品研究

- 拿到一个竞品，你会怎么系统拆解它（标题、图片、五点、价格、评论、QA）？
- Keepa / Helium 10 这些工具你会用吗？看竞品的销量趋势、价格历史、排名变化？
- 怎么从竞品的差评里挖出买家痛点？
- 怎么反查竞品在打什么关键词？

## 模块四：库存与 FBA 物流

> 库存管不好，前面所有努力都白费——断货是致命伤，滞销烧仓储费。

### FBA 基础

- FBA 和 FBM 有什么区别？分别适合什么情况？
- FBA 都收什么费？配送费、仓储费、长期仓储费、佣金——每项怎么算？
- 亚马逊的尺寸分段（Small Standard / Large Standard / Small Oversize / Large Oversize）你清楚吗？每个分段费率不同。
- 给你一个产品，你能判定它属于哪个尺寸分段吗（用重量 + 尺寸 + FBA 计算器）？
- 月度仓储费怎么算？淡旺季费率一样吗？
- 长期仓储费（271 天 / 365 天）什么条件触发、费率多少？

### 建仓发货

- 一个完整的 FBA 建仓发货流程，从打包到生成标贴，你能一口气走完吗？
- FNSKU 标签、外箱标分别是什么？怎么打印？
- 分布式入仓（Distributed Placement）和合仓（Inventory Placement）有什么区别？费用差多少？
- 货件状态有哪几个阶段（在途、接收中、已接收、有问题）？分别意味着什么？
- 货件「接收数量短缺」了怎么办？怎么申诉？

### 头程物流与清关

- 头程物流有哪些方式？海运快船、普船、空运、国际快递——分别什么场景用？
- 美森、以星这些快船和普船，时效、价格、稳定性差在哪？
- 自税和包税有什么区别？各自的风险在哪？
- 关税（Import Duty）是什么？不同品类的税率怎么查？
- 清关要什么资料？商业发票、装箱单、提单、HS Code 你都懂吗？
- 怎么挑靠谱的货代？看时效、价格、丢件率还是清关能力？

### 库存管理

- 后台库存数据分好几类（可售、预留、在途、转运中），每类什么意思？
- 一个产品的日均销量和周转天数，你会算吗？
- 要不要补货、补多少，你怎么判断？要考虑哪些因素？
- 什么是安全库存？为什么要有安全库存天数？
- 断货到底有多伤？排名掉、广告停、权重降——具体什么后果？
- **遇到断货风险，你会从哪里入手？** 提价、降广告、FBM 顶上——这些招你会用吗？
- IPI（库存绩效指标）分数是什么？分数低了会怎样（仓储受限）？
- 库存仓储限额是什么？超了会怎样？

### 库存调整

- 移除订单（Removal Order）怎么创建？移到哪里去？
- FBA Liquidations（清算）是什么？什么时候用？
- FBM 自发货的运费模板你会设置吗？

## 模块五：广告体系

> 入门阶段不要求你成为广告高手，但必须**看懂广告数据、能做基础优化**。

### 广告基础概念

- CPC 广告的扣费机制是什么？不点会扣钱吗？
- SP、SB、SD 三种广告有什么区别？展示位置在哪、分别适合什么场景？
- ACOS、TACOS、CPC、CR、ROAS 分别是什么？怎么算？关系是什么？
- 广告销售额和自然销售额的关系你搞清楚了吗？

### 广告账户结构

- 亚马逊广告的层级结构是什么（账户 → Campaign → Ad Group → 关键词）？
- 广告活动（Campaign）和广告组（Ad Group）有什么区别？为什么一个活动里要建多个组？
- 广告活动应该按什么逻辑拆？按产品、按词的类型、还是按匹配方式？

### SP 广告操作

- 怎么开一个自动广告？自动广告的四组（紧密、宽泛、同类、补充）分别跑什么词？
- 怎么开手动广告？广泛、词组、精准三种匹配，区别是什么？各举个例子。
- 竞价（Bid）是什么？怎么设置、怎么调？
- 三种竞价策略（固定、仅降低、提高和降低）各自适合什么场景？
- 「提高和降低」什么情况下会大幅超支？怎么控制？
- 广告位溢价（Placement Bid+）是什么？Top of Search 加价多少合适？
- 否定关键词怎么加？精准否定和词组否定有什么区别？
- 广告什么时候该加预算？怎么判断？

### 广告数据与报告

- 广告后台的核心数据（曝光、点击、CTR、CPC、花费、销售额、ACOS）你都看得懂吗？
- 搜索词报告（Search Term Report）在哪下？它能告诉你什么？
- 搜索词报告和投放报告（Targeting Report）有什么区别？
- 从搜索词报告里，你怎么挑出好词和坏词？分别怎么处理？
- 广告活动报告、商品报告分别有什么用？
- 怎么判断一个广告活动健不健康？看哪几个指标？

### SB 与 SD 广告

- SB 广告展示在哪？需要什么资质（品牌注册）？
- SB 广告有哪几种格式（商品集、品牌视频、旗舰店焦点）？
- SD 广告怎么投放（按兴趣、按商品）？展示在哪？
- SD 广告适合干什么？防守竞品、再营销、品类抢占——哪个场景用？

### 新品广告策略

- 新品上架后的蜜月期（Honeymoon Period）是什么？亚马逊会给什么扶持？
- 新品的广告怎么开？预算和竞价怎么定？
- 前期 ACOS 很高正常吗？到什么阶段要开始压？
- 自动广告跑出来的词，怎么筛选、什么时候转手动？
- Vine 计划是什么？新品怎么用它拿第一批评价？

## 模块六：定价与利润

> 定价直接决定利润，调错一次可能白卖一个月。

### 利润核算

- 一笔订单的钱是怎么被一层层扣掉的（佣金 → FBA 费 → 头程 → 产品成本 → 退货损耗）？最后剩多少？
- 给你一个 ASIN，你能手算出它的单件利润和利润率吗？
- 什么是盈亏平衡点？怎么算？
- 广告费怎么分摊到每个产品上？TACOS 的含义你清楚吗？

### 定价与调价

- 新品怎么定价？要参考哪些因素？
- List Price（划线价 / 市场价）怎么才会显示出来？
- 什么是参考价（Reference Price）？它影响什么？
- **调价的时候你会考虑什么？** 对购物车、广告、BSR 分别有什么影响？
- 什么是购物车（Buy Box）？哪些因素影响能不能拿到？
- 购物车丢了，常见原因是什么（被跟卖压价、提价太高、断货）？
- 小幅调价和大幅调价，对排名的影响有什么不同？

### 促销工具

- Coupon 怎么创建？什么时候扣费（被领取并使用才扣）？
- Coupon 折扣力度一般建议多少（5%–20%）？
- Prime 专享折扣至少要比原价低多少？
- Lightning Deal 和 7-Day Deal 有什么区别？报名条件、费用分别是什么？
- 秒杀前要做什么准备（库存、价格、BD 推荐）？
- 什么是 Was Price（促销价）？它怎么影响你的 List Price？
- 买赠促销（Promotion / Social Media Promo）怎么设置？

## 模块七：日常运营与判断力

> 每天打开电脑第一件事干什么、怎么排优先级、遇到问题怎么排查——这是运营的核心能力。

### 日常流程

- 一个运营每天开工的标准流程是什么？先看什么、后看什么？
- 每天必须盯的核心数据有哪些（销量、广告花费、ACOS、库存、账户健康）？
- 手上一堆事，你怎么排优先级？什么紧急、什么重要、什么可以等等？
- 每周、每月应该复盘什么？

### 异常排查

- **某条 Listing 销量突然掉了，你会从哪里入手排查？** 购物车 → 流量 → 转化 → 差评 → 跟卖 → 广告 → 竞品——这个顺序你熟吗？
- **广告 ACOS 突然飙高，你怎么查？** CPC 涨了？转化掉了？跑了不该跑的词？
- **Listing 突然没流量了，可能是什么原因？** 你会怎么一个个排除？
- 收到差评了，你会怎么处理？（分析原因 → 改进产品/Listing → 合规应对）
- BSR 排名突然波动，常见原因有哪些？

### 销量预估与旺季

- 怎么做销量预估？参考哪些数据（历史销量、趋势、季节性、广告预算）？
- 一年有哪些旺季（Prime Day、黑五网一、圣诞节）？旺季前要做什么特殊准备？
- 旺季备货要提前多久启动？物流和库存怎么规划？
- 旺季的广告预算和竞价通常怎么调？
- 旺季过后退货潮和滞销风险，你怎么应对？

### 售后与退货

- 买家要退款（全额 / 部分），你会怎么处理？退款对账户指标有什么影响？
- 什么是 A-to-Z 索赔？卖家的响应时效是多久？
- **遇到买家发消息，你会怎么回？** 24 小时内、不能留私人联系方式——这些规则你清楚吗？
- NCX 指标（负面体验）是什么？在哪看？
- 怎么分析退货原因（退货报告、Voice of Customer）？分析完怎么改进？
- Feedback 和 Review 有什么区别？分别怎么处理？

### 跟卖与防御

- 什么是跟卖？跟卖对 Listing 有什么危害？
- **被跟卖了，你会从哪里入手？** 品牌备案投诉、警告信、Test Buy——你会用哪些？
- 长期怎么防跟卖（品牌注册、Transparency、Project Zero、独家设计）？
- 购物车被跟卖抢走了，怎么办？

### 决策意识

- 什么是「高不可逆操作」（删 Listing、提交申诉、大幅调价）？做之前你应该先干什么？
- 为什么不能基于过期或不实数据做决策？
- **为什么不能同时改广告又改价格？** 出了问题你能说清是哪个改动导致的吗？
- 做完一个操作后，应该隔多久去看效果？当天就反复调整会怎样？
- 怎么做一个简单的决策复盘（做了什么、为什么、结果、下次怎么改）？

---

## 全部 ✅ 之后

如果你把上面七大模块、八十多个问题都打上了 ✅，意味着：

- 你能独立完成一个产品从上架、备货、广告、定价到日常维护的全流程
- 你能看懂后台绝大多数数据和报告，并从中读出问题和方向
- 你清楚哪些动作会伤账号、伤利润，并知道怎么规避和应对

这还不够——这只是**入门的及格线**。再往上，你要学的是：

- **怎么选品**（不只是判断别人选的，而是自己找到值得做的品）
- **怎么优化**（ACOS 压降闭环、Listing A/B 测试、关键词排名冲刺）
- **怎么打仗**（多 SKU 矩阵、新品冷启动、品牌建设）

这些就是五级课程体系里初级、中级、高级要解决的问题。

> 把基础铺满，是所有进阶的前提。这份清单，就是你出发前的体检报告。
