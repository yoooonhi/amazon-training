# 小白入门水平自测

> **栏目定位**：独立参考栏目，与「真实」运营实战经验、「广告打法手册」同级，不属于五级课程体系，不占学习进度。
> **这页讲什么**：一份覆盖入门运营全部基础知识的「体检清单」——不是一个一个知识点讲给你听，而是把「你应该懂的东西」变成问题摆出来，让你自己对照检查。

## 为什么单独开这个栏目

五级课程体系教你**怎么做事**，销冠经验栏目教你**怎么判断**。但两者都有一个隐藏前提：

> **基础概念不能有盲区。**

一个连 FNSKU 是什么都说不清的人，听再多「ACOS 压降闭环」也接不住；一个不知道二审为何物的人，再好的运营技巧也守不住账号。

这份清单就是那张**入门体检表**——它不教你新东西，它帮你**找出你已经会的、模糊的、完全不懂的**。模糊和不懂的部分，就是你接下来的学习清单。

::: tip 三个特点
1. **不是考试**——没有分数，没有及格线，纯粹是给你自己用的自检工具。
2. **不教你新东西**——它只问「你懂不懂」，懂了就打 ✅，不懂就去对应课程补。
3. **覆盖入门全部**——七大模块、八十多个问题，把一个新手该懂的基础知识铺满。
:::

## 怎么用这份清单

1. 打开 [完整自查清单](./01-checklist)，通读一遍，每个问题问自己：「我真的清楚吗？」
2. **会的打 ✅，模糊的标 ⚠️，不懂的圈出来**。
3. ⚠️ 和圈出来的部分，就是你的**学习清单**——对照五级课程体系和「真实」运营实战经验栏目去补。
4. 每隔一两周回来看一次，目标是**全部 ✅**。
5. 这份清单会随平台规则更新——亚马逊改了什么，对应的问题也要跟着更新。

## 七大模块一览

| 模块 | 核心问题 | 关键词 |
|---|---|---|
| 一、平台认知与账号安全 | 底线：什么绝对不能做、账号怎么维护 | 关联、二审、账户健康、合规红线 |
| 二、选品与采购 | 怎么判断一个产品值不值得做 | 市场容量、利润核算、供应链 |
| 三、Listing 搭建基本功 | 怎么搭一个合格的 Listing | 关键词调研、上架、A+、诊断 |
| 四、库存与 FBA 物流 | 怎么算补货、判断货件、预防断货 | FBA 费用、建仓、头程、IPI |
| 五、广告体系 | 怎么看懂广告数据、做基础优化 | SP/SB/SD、竞价、报告、蜜月期 |
| 六、定价与利润 | 怎么算利润、怎么调价、促销怎么用 | 利润链、Buy Box、Coupon、Deal |
| 七、日常运营与判断力 | 每天怎么开工、遇到问题怎么排查 | 日报、异常排查、旺季、跟卖、决策 |

## 谁应该看

- **刚入门的新手**——用它找出盲区，制定学习计划。
- **准备上岗的运营**——全部 ✅ 之前，不建议独立接手店铺。
- **带新人的老手**——用它当考核清单，一眼看清新人哪里还差。
- **自学的卖家**——用它评估自己是不是真的「入门」了。

## 全部 ✅ 之后意味着什么

把上面七大模块、八十多个问题都打上 ✅，意味着：

- 你能独立完成一个产品从上架、备货、广告、定价到日常维护的全流程
- 你能看懂后台绝大多数数据和报告，并从中读出问题和方向
- 你清楚哪些动作会伤账号、伤利润，并知道怎么规避和应对

但这只是**入门的及格线**。再往上，是五级课程体系里初级、中级、高级要解决的问题——怎么优化、怎么打仗、怎么做品牌。
