# 第3节 · 深圳电子口岸制卡

## 一、为什么还要制卡

海关备案解决的是“企业具备什么身份”，电子口岸法人卡、操作员卡解决的是“谁有权代表企业登录和操作”。

两张卡分工不同：

| 卡类型 | 主要用途 |
|---|---|
| 法人卡 | 企业权限管理、操作员管理、重要授权确认 |
| 操作员卡 | 日常登录、申报、查询和业务操作 |

日常业务不应多人共用法人卡，也不要让物流商长期保管企业卡和密码。

## 二、深圳办理入口

海关备案通过后，可通过中国电子口岸全国通办系统或深圳电子口岸制卡服务入口发起“企业新入网/电子口岸制卡”申请。

通常流程：

> 基础信息 → 电子口岸制卡 → 经办人 → 提交 → 审核制卡 → 领取

## 三、基础信息怎么填

本课程统一为深圳注册企业：

| 字段 | 填写方法 |
|---|---|
| 单位名称 | 与营业执照一致 |
| 统一社会信用代码 | 与营业执照一致 |
| 企业类型 | 普通有限公司选“有限责任公司” |
| 主要经营场所（住所） | 广东省 / 深圳市 / 营业执照所在区 |
| 详细地址 | 营业执照登记住所完整地址 |
| 所属分中心 | 深圳制卡中心 |
| 制卡机构 | 深圳制卡中心 |
| 发卡机构 | 深圳制卡中心 |

::: warning “主要经营场所（住所）”不是临时办公点
这个字段按营业执照住所填写。即便员工在其他区远程办公、货物存放在第三方仓库，也不能用仓库或临时工位替代企业住所。
:::

## 四、申请哪些卡

首次新入网通常至少申请：

- 法人卡一张
- 操作员卡一张

操作员应选择实际负责报关、单一窗口或出口业务的人。法人卡持有人和操作员卡持有人应按系统规则分别填报，不能为了省事随意重复人员。

## 五、主体资格证明怎么准备

按页面最新提示准备营业执照复印件，常见要求包括：

- 加盖本企业公章
- 不得加盖合同章或其他业务章
- 在营业执照复印件空白处注明同意办理电子口岸制发卡及相关业务
- 由法定代表人/负责人按要求签名
- 标注申请日期

扫描时确保公章、签名、文字和营业执照二维码清晰完整。

## 六、经办人怎么选

经办人应当：

- 本人知情并同意办理
- 能接收审核电话和短信
- 能在需要时到深圳制卡窗口领取
- 身份证件在有效期内
- 与申请表中的姓名、手机号完全一致

在线审核通过后，全国通办公开流程通常要求申请中的经办人或法定代表人携身份证明到所选制卡机构领取。除非深圳办理页面明确提供邮寄选项并经窗口确认，否则不要默认首次新办卡可以邮寄。

## 七、提交后怎么看状态

| 总状态 | 单据状态 | 说明 |
|---|---|---|
| 暂存 | 未提交 | 资料仍可编辑 |
| 办理中 | 待资料审核 | 已成功提交，等待审核 |
| 办理中 | 待制卡/制卡中 | 资料通过，正在制卡 |
| 审核不通过 | 显示失败原因 | 按意见修改后重提 |
| 办结 | 制卡完成/可领取 | 按通知领取 |

保存以下信息：

- 业务申请单号
- 申请时间
- 回执文件
- 审核状态截图
- 审核不通过原因（如有）

不要因为一两天没有变化就重复申请。深圳公开指引中，新入网业务通常按受理后约4个工作日办结掌握，具体仍以状态和通知为准。

## 八、领卡与初始化

状态显示“办结/可领取”后：

1. 核对领取地点和办公时间
2. 由申请中的经办人或法定代表人携身份证明前往
3. 按页面要求携带回执、营业执照等材料
4. 领取法人卡、操作员卡及介质
5. 安装电子口岸客户端、控件和驱动
6. 修改初始密码
7. 分别测试法人卡和操作员卡登录
8. 用法人卡核对、配置操作员权限

## 本节完成标准

- [ ] 基础信息与营业执照一致
- [ ] 所属、制卡、发卡机构均为深圳
- [ ] 法人卡、操作员卡均已申请
- [ ] 经办人可以本人到场领取
- [ ] 已保存申请回执和申请单号
- [ ] 两张卡均可正常登录
- [ ] 已修改初始密码并建立保管制度
