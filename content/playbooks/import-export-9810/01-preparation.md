# 第1节 · 开始前准备

## 一、统一示例场景

本课程只使用以下虚拟场景，不对应任何真实企业：

| 项目 | 课程统一设定 |
|---|---|
| 企业称呼 | 深圳示例公司 |
| 企业类型 | 有限责任公司 |
| 注册地 | 广东省深圳市某区 |
| 实际经营地 | 深圳市，与营业执照登记住所一致 |
| 经营模式 | Amazon FBA，货物发往境外仓后再零售 |
| 计划监管方式 | 9810 跨境电子商务出口海外仓 |
| 商品类型 | 不涉及许可证和敏感监管的普通日用商品 |

页面截图、申请单编号、身份证号、手机号码、统一社会信用代码、海关编码等一律不使用真实数据。

## 二、先检查营业执照

营业执照经营范围建议包含：

- 货物进出口
- 互联网销售（除销售需要许可的商品）
- 与实际商品相匹配的销售类目

如果缺少“货物进出口”，先通过深圳市场监管渠道办理经营范围变更，再进入海关备案。

同时核对：

- 企业名称、统一社会信用代码是否准确
- 法定代表人是否与当前登记一致
- 登记住所是否可联系、能接收监管文书
- 企业状态是否正常存续
- 商品是否确实属于经营范围和许可范围

## 三、税务身份必须提前确认

不要等货物离境后才问会计“这票怎么免税”。至少提前确认四项：

1. 公司是一般纳税人还是小规模纳税人？
2. 采购能否取得增值税专用发票、普通发票或其他有效凭证？
3. 企业所得税当前是查账征收还是其他经税务机关确认的方式？
4. Amazon销售款准备通过哪个公司账户或合规支付机构收取？

| 典型情况 | 首先研究的方向 |
|---|---|
| 一般纳税人，采购有合规进项凭证 | 出口退（免）税 |
| 小规模纳税人 | 出口增值税免税，不产生进项退税 |
| 采购未取得有效凭证 | 先向深圳主管税务机关确认能否适用相关免税政策 |
| 使用个人账户收款 | 先调整为公司主体的合规收款链路 |

::: danger 不要把“无票”理解成“不需要采购证据”
即使某批货物最终符合增值税免税条件，采购合同、付款记录、入库记录、供应商信息和商品来源仍然要真实可追溯；企业所得税成本扣除也有独立的凭证要求。
:::

## 四、准备两个管理人员

海关备案通常至少需要：

- 财务负责人
- 企业关务负责人

填写原则：

- 使用真实、有效、本人知情的信息
- 手机号码可以正常接听监管部门电话
- 身份证件在有效期内
- 同一人同时负责多家企业并非当然禁止，但必须确实承担相应职责
- 不要为了“填满字段”虚构人员

## 五、准备电子材料

建议建立一个独立文件夹，按以下结构保存：

```text
01-营业执照
02-法人及经办人证件
03-海关备案申请
04-电子口岸制卡
05-税务备案
06-外汇及银行
07-报关委托
08-商品HS资料
09-每票报关资料
10-Amazon销售与收汇
```

常用资料包括：

- 营业执照原件扫描件及加盖公章的复印件
- 法定代表人、经办人、操作员身份证明
- 公司公章
- 企业中英文名称和中英文地址
- 联系人、固定电话或手机、电子邮箱
- Amazon店铺或平台主体证明
- 财务负责人、关务负责人信息

## 六、先确定英文信息

英文名称和英文地址提交后应保持稳定，并与后续商业发票、装箱单和报关资料一致。

填写建议：

- 英文名称使用完整、统一的拼写
- 地址按“房间/楼层—门牌—道路—街道—区—深圳—广东—中国”逻辑表达
- 不擅自添加营业执照不存在的分公司、集团或品牌字样
- 不把Amazon店铺名当作企业英文名称

## 七、本节完成标准

- [ ] 营业执照含货物进出口
- [ ] 企业登记住所、法定代表人信息准确
- [ ] 已确认一般纳税人或小规模纳税人身份
- [ ] 已确认采购发票和付款链路
- [ ] 财务负责人、关务负责人均已确定
- [ ] Amazon店铺主体与出口主体关系可说明
- [ ] 电子材料文件夹已经建立
- [ ] 企业英文名称和地址已有统一版本
