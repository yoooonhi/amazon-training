# 第2节 · 海关备案

## 一、进入办理入口

打开[中国国际贸易单一窗口](https://www.singlewindow.cn/)，注册企业账号并选择法人及其他组织相关入口登录。

常见路径为：

> 业务应用 → 口岸执法申报 → 企业资质 → 资质备案 → 备案申请

页面名称会更新，但核心业务仍是海关企业通用资质备案。

## 二、9810企业应选择哪两个资质

在“报关单位及相关资质”下选择：

- **进出口货物收发货人**
- **跨境电子商务电商企业**

::: danger 不要误选“报关企业”
“报关企业”是接受其他进出口企业委托、专门提供报关服务的经营主体。普通Amazon卖家只是使用自己的企业抬头出口，应备案为“进出口货物收发货人”，日后委托专业报关行即可。

误选报关企业可能导致整张申请被退回或不予受理。
:::

自2024年底起，开展9810业务无需再单独办理“出口海外仓业务模式备案”；完成报关单位和跨境电商企业备案后，仍需在实际申报环节传输订仓、交易和物流数据。

## 三、深圳企业常见字段

| 字段 | 深圳普通企业填写原则 |
|---|---|
| 企业名称 | 与营业执照完全一致 |
| 统一社会信用代码 | 与营业执照完全一致 |
| 企业类型 | 按营业执照公司类型选择，普通有限公司选“有限责任公司” |
| 工商注册地址 | 与营业执照住所逐字核对 |
| 英文名称 | 使用统一的企业英文名称 |
| 英文地址 | 使用完整、稳定的英文拼写 |
| 经济区划 | 深圳普通企业通常选择“01—经济特区” |
| 统计经济区域 | 非保税区、自贸区等特殊区域的企业通常选择“深圳市其他地区” |
| 备案海关 | 深圳企业按系统及深圳指引选择，普通情形通常为福中海关 |
| 行业种类 | 选择最能代表主营业务的类别 |

深圳经济特区范围自2010年起扩大到全市；深圳官方备案样例中，经济区划使用“01（经济特区）”。但如果企业注册在前海、综合保税区等特殊区域，应按真实注册地址和系统选项填写，不能套用普通企业答案。

## 四、注册地址与实际经营地址

本课程统一假设深圳注册、深圳经营，且两者一致：

- “工商注册地址”“住所”“主要经营场所（住所）”按营业执照填写
- 详细地址不得填共享仓库、货代地址或员工住址
- 如果系统另有“其他经营地址”，再根据真实情况填写

不要把制卡领取地点当成企业住所，也不要因为货物从某个口岸离境就修改注册地址。

## 五、管理人员信息

至少完整录入：

1. 财务负责人
2. 企业关务负责人

需要核对：

- 姓名、证件类型、证件号码
- 手机号码和电子邮箱
- 职务和人员类型
- 是否与企业实际职责一致

如果同一个人确实兼任两项职责，应以系统是否允许及实际职责为准；不得未经本人同意使用其身份信息。

## 六、打印、签章和上传

填写完成后，按页面提示生成《报关单位备案信息表》或对应申请表：

1. 下载并核对所有字段
2. 打印申请表
3. 按要求加盖企业公章
4. 法定代表人或负责人在指定位置签字
5. 扫描成清晰、完整文件
6. 上传并提交

不得出现：

- 公章遮挡统一社会信用代码
- 页面缺失或裁边
- 地址与营业执照不一致
- 签字日期早于材料生成日期太多
- 上传未盖章版本

## 七、怎么看审批状态

| 状态 | 含义 | 下一步 |
|---|---|---|
| 已提交/待审核 | 申请成功进入队列 | 等待，不要重复提交 |
| 退回修改 | 字段或材料可修正 | 查看海关意见后修改 |
| 海关不予受理 | 申请类型或主体不符合 | 查看原因，重新发起正确申请 |
| 审批通过 | 本次申请通过 | 查询备案信息和海关编码 |
| 已备案 | 资质已生效 | 不再重复申请 |

如果旧申请“不予受理”，而后续正确申请已经“审批通过/已备案”，旧记录留在查询列表中通常不影响当前有效资质。

## 八、备案完成后的核验

进入：

> 综合查询 → 备案信息查询 / 申请单查询

确认以下两项均显示“已备案”：

- 进出口货物收发货人
- 跨境电子商务电商企业

同时保存：

- 审批结果页面
- 海关备案编码
- 备案申请表和上传材料
- 海关意见或受理回执

## 本节完成标准

- [ ] 只选择了正确的两个资质
- [ ] 经济区划、统计经济区域、备案海关符合深圳实际
- [ ] 地址与营业执照一致
- [ ] 财务负责人、关务负责人均已录入
- [ ] 两项资质均显示审批通过/已备案
- [ ] 已保存海关编码和申请材料
