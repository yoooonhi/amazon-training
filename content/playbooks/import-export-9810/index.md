# 进出口权资质（海关备案）（9810）

> **场景约定**：本课程中的企业名称、地址、人员和编号均为虚拟占位信息。统一假设企业注册地、实际经营地、制卡地和主要出口操作地均在深圳，不使用任何真实企业或个人数据。

## 这门课解决什么问题

很多教程把“进出口权”概括成三步：海关备案、电子口岸制卡、出口退（免）税备案。这个方向没有错，但如果目标是以自己的深圳公司抬头，把货物发往 Amazon FBA 海外仓并使用 **9810（跨境电子商务出口海外仓）**申报，仅有三张资质并不足以完成一次合规出口。

完整闭环还包括：

- 确认营业执照和纳税人身份
- 备案“进出口货物收发货人”和“跨境电子商务电商企业”
- 申领电子口岸法人卡、操作员卡
- 确认出口退税、免税或无票免税路径
- 办理贸易外汇收支企业名录
- 接入9810交易、订仓和物流数据通道
- 与报关行建立电子代理报关委托
- 建立商品HS编码和申报资料
- 完成首票申报、放行、离境和报关单归档
- 对接 Amazon 实际销售、收汇、退货和税务核算

::: warning 先记住一个核心判断
**9810是海关监管方式代码，不是自动免税资格。**

能否退税、免税或适用综试区无票免税，要结合纳税人身份、采购凭证、申报方式和深圳主管税务机关口径判断。
:::

## 全流程地图

```text
营业执照与税务身份检查
        ↓
中国国际贸易单一窗口注册
        ↓
海关备案两个主体资质
        ↓
取得海关编码
        ↓
深圳电子口岸法人卡、操作员卡
        ↓
出口退（免）税备案 + 外汇名录
        ↓
9810数据通道 + 报关行委托
        ↓
商品归类与首票资料
        ↓
9810申报、查验、放行、离境
        ↓
Amazon销售、税务、收汇、库存核算
```

## 学完后的验收标准

完成本课程并不等于“看完页面”，而是能够拿出以下证据：

- 海关企业信息中两个资质均为“已备案”
- 电子口岸法人卡、操作员卡可正常登录
- 已确定本企业的税务处理路径
- 已完成或确认贸易外汇收支企业名录
- 报关行明确支持9810数据传输和本企业抬头报关
- 每个出口SKU都有HS编码和申报要素
- 首票出口后取得本企业抬头的9810报关单
- 能把报关单、FBA Shipment、Amazon销售和对公收款对应起来

::: info 规则更新时间
本课程按 **2026年8月** 可查询的公开规则整理。海关、税务、电子口岸和深圳本地平台会更新页面及办理口径，首次办理时仍应以系统提示及主管部门答复为准。
:::
