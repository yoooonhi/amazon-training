# 亚马逊9810自营出口实操课

> **从海关备案、电子口岸制卡到首票报关与免税申报**

> **场景约定**：本课程中的企业名称、地址、人员和编号均为虚拟占位信息。统一假设企业注册地、实际经营地、制卡地和主要出口操作地均在深圳，不使用任何真实企业或个人数据。

## 这门课解决什么问题

很多教程把“进出口权”概括成海关备案、电子口岸制卡和出口退（免）税备案。但第三项并非所有企业都要办理：本课程主线企业是**增值税小规模纳税人，只适用出口免税、不申请出口退税**，因此无需提交出口退（免）税备案。

如果目标是以自己的深圳公司抬头，把货物发往 Amazon FBA 海外仓并使用 **9810（跨境电子商务出口海外仓）**申报，真正需要分清的是“前置资质”和“日常合规”。

完整闭环还包括：

- 确认营业执照和纳税人身份
- 备案“进出口货物收发货人”和“跨境电子商务电商企业”
- 申领电子口岸法人卡、操作员卡
- 根据纳税人身份确认退税或免税路径
- 建立第三方支付机构到公司人民币对公账户的收款链路
- 接入9810交易、订仓和物流数据通道
- 与报关行建立电子代理报关委托
- 建立商品HS编码和申报资料
- 完成首票申报、放行、离境和报关单归档
- 对接 Amazon 实际销售、收汇、退货和税务核算

::: warning 先记住两个核心判断
1. **9810是海关监管方式代码，不是自动免税资格。**
2. **小规模纳税人出口免税，不等于不记账、不申报、不留凭证。**

能否退税、免税或适用其他政策，要结合纳税人身份、采购凭证、商品类型和主管税务机关口径判断。
:::

## 全流程地图

```text
营业执照与税务身份检查
        ↓
中国国际贸易单一窗口注册
        ↓
海关备案两个主体资质
        ↓
取得海关编码
        ↓
深圳电子口岸法人卡、操作员卡
        ↓
税务路径判断
├─ 小规模纯免税：不办出口退（免）税备案
└─ 一般纳税人申请退税：先办出口退（免）税备案
        ↓
收款路径判断
├─ 第三方支付机构结汇到人民币对公户：通常无需外币账户
└─ 企业直接收取并持有外币：向开户行确认名录与外币账户
        ↓
9810数据通道 + 报关行委托
        ↓
商品归类与首票资料
        ↓
9810申报、查验、放行、离境
        ↓
Amazon销售、税务、收汇、库存核算
```

## 学完后的验收标准

完成本课程并不等于“看完页面”，而是能够拿出以下证据：

- 海关企业信息中两个资质均为“已备案”
- 电子口岸法人卡、操作员卡可正常登录
- 已确认小规模出口免税路径，并明确无需办理出口退（免）税备案
- 已建立第三方支付机构到同名人民币对公账户的收款链路
- 报关行明确支持9810数据传输和本企业抬头报关
- 每个出口SKU都有HS编码和申报要素
- 首票出口后取得本企业抬头的9810报关单
- 能把报关单、FBA Shipment、Amazon销售和对公收款对应起来

::: info 规则更新时间
本课程按 **2026年9月** 可查询的公开规则及实际办理结果校正。海关、税务、电子口岸和深圳本地平台会更新页面及办理口径，首次办理时仍应以系统提示及主管部门答复为准。
:::
