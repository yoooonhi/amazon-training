# 第6节 · 首票9810出口

## 一、首票要小，不要乱

第一次使用新企业抬头做9810，目标不是把所有库存一次发完，而是验证：

- 海关资质是否正常识别
- 电子口岸卡和委托是否有效
- 9810数据是否成功传输
- 商品编码和申报要素是否正确
- 报关单能否进入税务数据链路
- Amazon Shipment和报关批次能否对上

选择SKU少、监管条件简单、资料完整的小批量做首票。

## 二、为每个SKU建立申报档案

| 字段 | 示例填写原则 |
|---|---|
| 内部SKU | 与采购、仓库、Amazon一致 |
| 中文品名 | 使用规范具体品名，不写“日用品”“配件” |
| 英文品名 | 与商业发票一致 |
| 材质 | 如实写主要材料 |
| 用途 | 描述商品实际用途 |
| 品牌/型号 | 有则如实申报，无品牌不得虚构 |
| HS编码 | 依据商品结构、材质和用途归类 |
| 申报要素 | 按当期海关规范完整填写 |
| 法定计量单位 | 与HS编码要求一致 |
| 成交计量单位 | 与商业单据和实际包装一致 |
| 单价、总价 | 有真实、合理、可解释的定价依据 |
| 原产国 | 按实际生产地 |
| 最终目的国 | 海外仓所在国家或实际申报要求 |

普通商品也可能涉及检验检疫、知识产权、出口管制或目的国认证。不能仅凭商品“不带电、不是液体”就判断没有要求。

## 三、首票资料包

### 企业与委托资料

- 海关备案信息
- 电子口岸卡状态
- 电子代理报关委托
- 报关服务合同

### 采购与商品资料

- 采购合同/订单
- 供应商信息
- 采购发票或其他真实采购凭证
- 公司付款记录
- 商品图片、规格书、材质说明
- 品牌授权或知识产权说明（如适用）

### Amazon与海外仓资料

- 店铺主体证明
- FBA Shipment ID
- Amazon入仓计划
- 海外仓地址
- SKU、ASIN、FNSKU对应表

### 物流和报关资料

- 商业发票
- 装箱单
- 箱数、毛重、净重和尺寸
- 国内提货及国际物流信息
- 订仓单或提运单信息
- 9810交易、订仓和物流数据传输结果

## 四、报关草单审核清单

报关行提交后，不要只回复“可以”。逐项核对：

| 报关字段 | 核对重点 |
|---|---|
| 境内发货人 | 深圳示例公司完整法定名称 |
| 海关编码 | 本企业编码 |
| 申报单位 | 受委托报关行 |
| 监管方式 | 9810 |
| 运输方式 | 与实际物流一致 |
| 离境口岸 | 与实际出口路线一致 |
| 运抵国/地区 | 与海外仓和运输一致 |
| 成交方式 | 与报价和费用承担一致 |
| 币制 | 与商业发票一致 |
| 商品编码 | 与商品归类档案一致 |
| 商品名称及申报要素 | 具体、完整、真实 |
| 数量及单位 | 与装箱单、Shipment一致 |
| 毛重、净重、件数 | 与实际交仓数据一致 |
| 单价、总价 | 有合理依据，不高报低报 |

::: warning 生产销售单位不要照抄
“境内发货人”和“生产销售单位”不是同一个概念。贸易公司采购后出口时，应根据实际采购、生产和销售关系填写，由报关行提出方案、企业审核证据，不能一律填成同一家公司。
:::

## 五、申报到离境的状态

```text
电子数据预传输
   ↓
报关单申报
   ↓
海关审单
   ├─ 接受申报
   ├─ 退单修改
   └─ 布控查验
   ↓
放行
   ↓
装运离境
   ↓
结关/形成可查询数据
```

“海关放行”表示允许货物进入后续装运环节，不必然等于运输工具已经实际离境；税务和收汇核对时还要关注离境、结关等后续状态。

## 六、遇到查验怎么办

- 立即核对申报品名、数量、重量和实物
- 提供商品说明书、采购凭证和归类依据
- 不擅自改包装、抽换商品或补做虚假文件
- 记录查验时间、地点、结果和产生费用
- 查验后如需改单，保存改单前后版本和原因

## 七、出口后立即收回资料

- 9810出口报关单
- 海关放行和离境状态
- 查验记录（如有）
- 国际提运单/物流轨迹
- 商业发票、装箱单最终版
- 数据传输回执
- FBA海外入库结果
