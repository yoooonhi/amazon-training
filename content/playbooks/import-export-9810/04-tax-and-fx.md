# 第4节 · 税务与收款

## 一、先把三个概念分开

| 概念 | 解决的问题 |
|---|---|
| 9810 | 海关如何监管“先发海外仓、后续销售”的货物 |
| 出口退（免）税备案 | 首次申报出口退（免）税或申请相关证明前办理的税务备案 |
| 无票免税 | 特定条件下，未取得有效进货凭证的出口货物免征增值税、消费税 |

::: danger 9810 ≠ 自动无票免税
只要报关单写9810就自动免税，是错误理解。税务处理必须结合纳税人身份、采购凭证、货物类型、深圳综试区平台登记和主管税务机关口径判断。
:::

## 二、小规模纯免税是否办理出口退（免）税备案

::: tip 本课程主线结论
深圳示例公司是小规模纳税人，只适用出口增值税免税、不申请出口退税，也不申请开具出口退（免）税证明，因此**不办理出口退（免）税备案**。

2026年管理办法规定，纳税人于首次申报出口退（免）税或申请开具相关证明时办理备案；小规模纳税人出口货物属于增值税免税范围。两项规则应当结合判断，不能继续沿用“有出口业务就一律先备案”的旧教程。
:::

如果误进入电子税务局并提交了备案申请：

1. 先联系主管税务机关说明“小规模、只做免税、不申请退税”
2. 有撤回按钮则自行撤回
3. 无撤回按钮则请主管税务机关退回或不予受理
4. 已退回后不再重复提交，也无需另办替代备案

电子税务局可能根据小规模身份把企业类型锁定为“其他单位”，并把退（免）税办法置灰。这只是系统限制，不代表应继续提交备案。是否需要办理，以主管税务机关基于实际业务作出的答复为准。

## 三、四种常见税务路径

### 路径A：一般纳税人，有合规进项凭证

重点研究出口退税：

- 采购发票与出口商品、数量、供应商一致
- 采购付款和入库记录真实
- 报关单境内发货人为本企业
- 出口商品退税率和申报期限符合规定

9810货物尚未在海外仓销售时，现行政策允许符合条件的企业按“离境即退税、销售再核算”办理出口预退税。

### 路径B：小规模纳税人（本课程主线）

小规模纳税人出口普通货物适用增值税免税，没有可退的进项税：

- 不办理出口退（免）税备案
- 不申报9810“离境即退税”或出口预退税
- 按期在增值税申报中申报出口免税销售额
- 正常确认收入、成本并申报企业所得税
- 保存报关、采购、物流、Amazon销售及收款证据

### 路径C：未取得有效采购凭证

先判断是否符合综试区相关免税条件，不得自行假定：

- 企业是否在综试区注册并符合主体范围
- 是否在深圳跨境电商线上综合服务平台登记规定数据
- 是否通过符合要求的电子商务出口方式申报
- 商品是否属于取消出口退（免）税的货物
- 深圳主管税务机关是否认可本企业9810业务的具体申报路径

在首票出口前，通过12366或主管税务机关形成可留存的咨询记录。

### 路径D：货物已在海外仓实际销售

按照实际销售情况、出口报关单和现行出口退（免）税规则办理，不再把已售货物当作未售库存统一申报预退税。

## 四、9810“离境即退税”怎么理解

自2025年起，符合条件的9810货物在报关离境后即可申报出口退（免）税：

- 已实现销售：按现行规定申报
- 尚未实现销售：可先申报出口预退税
- 后续销售：再根据实际销售情况进行核算
- 滞销、退货或未实现销售：按规定调整或缴回相应预退税

外贸企业申报预退税时，需要按规则使用单独关联号；业务类型使用税务系统规定的“海外仓预退”标识。具体表单由会计按当期电子税务局操作。

## 五、企业所得税不能忽略

增值税免税不等于企业所得税免税。

企业仍需：

- 真实确认Amazon销售收入
- 保存采购成本和费用凭证
- 区分平台佣金、广告费、仓储费、配送费、退款和赔偿
- 按适用汇率折算外币收入
- 对无发票成本的税前扣除风险进行处理

综试区企业所得税核定征收有独立条件和程序，不能自行按某个固定比例计算，必须以主管税务机关确认结果为准。

## 六、第三方支付机构收款是否需要外币账户

本课程统一收款路径：

> Amazon外币回款 → 第三方支付机构企业账户 → 平台结汇成人民币 → 提现至同一公司的人民币对公账户

::: tip 本课程主线结论
这条路径下，结售汇由具备相应能力的支付机构及合作银行处理，企业通常**不需要另开国内银行外币账户**，也不应把“开外币账户”列为9810发货前的统一门槛。

如果以后改为企业直接接收境外电汇、需要持有外币，或者支付机构/开户行基于累计金额与真实性审核提出要求，再向银行确认贸易外汇收支名录和外币账户。
:::

第三方支付机构不是“个人收款替代品”。企业仍应完成企业账户实名认证，并按要求提供店铺、交易、物流、报关和受益所有人资料。

## 七、Amazon收款账户原则

- Amazon店铺主体、第三方支付账户和出口企业关系可解释
- 使用公司名义的合规收款账户
- 最终结算至公司对公账户
- 不长期通过法人、员工或亲属个人账户收取企业销售款
- 保存平台结算单、支付机构流水和银行入账记录
