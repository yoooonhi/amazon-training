# 第7节 · 出口后闭环

## 一、发到FBA不等于全部销售

9810货物离境并进入Amazon FBA仓库后，通常仍是企业的海外库存。应区分：

- 已离境未入仓
- 已入仓未销售
- 已销售未结算
- 已结算未收汇
- 已退款/退货
- 丢失、损坏或平台赔偿
- 滞销、销毁或退运

不能在货物刚离境时，就把整批货物都当作已经销售给境外消费者。

## 二、建立一条完整证据链

```text
9810报关单项号
  ↕
内部SKU / ASIN / FNSKU
  ↕
FBA Shipment ID与海外入库
  ↕
Amazon订单、退款和库存变动
  ↕
Amazon结算单与平台费用
  ↕
支付机构流水
  ↕
公司对公银行入账
  ↕
增值税、企业所得税和会计账簿
```

## 三、每月保存哪些Amazon报表

- Transaction Report
- Settlement Report
- FBA Inventory Ledger
- Shipment和入库差异报告
- 退款、退货和赔偿记录
- 平台佣金、广告费、仓储费、配送费
- 移除、销毁和长期仓储费用

报表下载后按站点、月份和结算周期归档，不只保存后台截图。

## 四、小规模免税与一般纳税人退税分开处理

本课程主线企业是小规模纳税人：

- 不办理出口退（免）税备案
- 不申报出口预退税
- 按期申报出口免税销售额
- 保存报关单、合法购进凭证、物流资料和销售证据
- 正常确认企业所得税收入和成本

免税不是“不开发票、不记账、不申报”。实际销售时点、申报栏次和凭证形式由会计按当期申报表及主管税务机关口径处理。

以下内容只适用于已选择退税路径的一般纳税人：

如果企业已对未售9810货物办理出口预退税：

- 已销售部分按实际销售情况核算
- 未销售部分继续跟踪
- 滞销、退货等情况按规定调整
- 应缴回的预退税及时申报处理
- 不同报关单和项号不要混为一个总数

现行政策规定了预退税后的核算期限，企业应按照电子税务局推送清单和主管税务机关要求，在期限内完成核算，不能等到税务风险提示后再补账。

## 五、收汇金额为什么可能不同

9810出口报关金额与最终收汇可能因为以下事项出现差异：

- Amazon佣金和配送费
- 广告费、仓储费
- 促销折扣
- 退款退货
- 汇率变动
- 丢件赔偿
- 部分库存尚未销售

差异可以存在，但必须可解释。财务应建立“报关金额—销售额—平台扣费—净结算—银行入账”调节表。

## 六、会计和税务的月度动作

1. 下载并锁定当月Amazon报表
2. 更新海外库存数量和成本
3. 确认当期实际销售收入
4. 归集平台佣金、广告和物流费用
5. 核对支付机构和银行入账
6. 更新每张9810报关单的销售进度
7. 小规模企业完成出口免税销售额申报；退税企业另按规定申报退（免）税
8. 计提并申报企业所得税相关数据
9. 标记退货、滞销、销毁和赔偿异常

## 七、退货和滞销怎么留证

保存：

- Amazon退货订单和原因
- 海外仓退件、移除或销毁记录
- 退运物流和进口申报资料
- 平台赔偿通知
- 库存盘点差异说明
- 相关税务调整记录

符合特定期限和条件的跨境电商出口退运货物可能享受进口环节便利政策，但必须按当期有效规则办理，不能直接以普通快递退回后不申报。

## 八、年度复核

每年至少进行一次：

- 海关企业信息是否需要变更
- 电子口岸数字证书是否临近到期
- 操作员是否仍在职、权限是否合理
- 报关行委托是否仍有效
- 纳税人身份、免税/退税路径和公司收款账户是否发生变化
- 所有出口批次是否已完成销售/库存核对
- 是否存在长期未收汇或无法解释的金额差异
- 商品HS编码和监管条件是否更新
